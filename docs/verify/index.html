How the check works

  1. Re-hash every record. Each audit record stores the hash of the one before it, so changing, removing or reordering any record breaks the chain from that point on.
  2. Rebuild the Merkle root over the sealed records and compare it with the root the arena sealed.
  3. Check the Ed25519 signature on that root (and on the report) with the public key in the file.
  4. Reconstruct the finding — attacks, blocks, commitment — from the log alone, with no live arena.

A valid signature proves the record was not changed after it was signed, by whoever holds that key. To be sure the key belongs to the run you watched, compare the key fingerprint shown here with the one from that run.
